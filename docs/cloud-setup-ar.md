# إعداد التخزين السحابي لمِداد

## قاعدة البيانات: Cloud Firestore

1. أنشئ مشروع Firebase واختر خطة Spark المجانية.
2. فعّل Cloud Firestore في المنطقة المناسبة، وابدأ بقواعد تمنع الوصول العام. الخادم فقط يستخدم حساب الخدمة.
3. أنشئ Service Account محدود الصلاحيات (Firestore access)، وخزّن JSON كاملًا كـ `FIREBASE_SERVICE_ACCOUNT_JSON` في إعدادات Vercel، و`FIRESTORE_PROJECT_ID` باسم المشروع.
4. بعد إعادة النشر، تعرض لوحة القيادة Firestore كمصدر البيانات. تُحفظ الأفكار وحالاتها هناك.

تشمل الحصة المجانية الحالية قاعدة واحدة مؤهلة، 1 GiB بيانات، و50 ألف قراءة و20 ألف كتابة يوميًا؛ راجع الأسعار وحدود الحساب قبل الاستخدام الإنتاجي.

## الملفات: Cloudflare R2

1. أنشئ bucket على R2 في فئة Standard، ومفتاح API بصلاحيات هذا الـ bucket فقط.
2. أضف `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, و`R2_BUCKET` إلى Vercel. لا تضعها في واجهة مِداد أو Git.
3. عند الإنتاج، تُرفع الأصول إلى مسارات تبدأ بمعرّف الفكرة. اترك `R2_PUBLIC_BASE_URL` فارغًا لاستخدام رابط قراءة موقّع قصير العمر.
4. لا تنشئ نطاقًا عامًا إلا إذا كنت تريد نشر الوسائط للجميع؛ ملفات هذا التطبيق قد تتضمن محتوى غير منشور.

تتضمن الخطة المجانية شهريًا 10 GB-month، ومليون عملية Class A، و10 ملايين عملية Class B، دون رسوم نقل بيانات خارجة. قد يتطلب فتح R2 إعداد وسيلة دفع، حتى لو بقي الاستخدام ضمن الحصة المجانية؛ راجع لوحة Cloudflare قبل التفعيل.

## تحقق بعد الربط

- افتح `/api/overview` وتأكد أن `data_store.configured` و`file_store.configured` بقيمة `true`.
- أنشئ فكرة اختبارية ثم تحقق من وجود مستندها في مجموعة `ideas`.
- أنتج ملفًا تجريبيًا صغيرًا وتحقق من ظهوره في bucket مع صلاحية وصول خاصة.
- لا تعتبر تحليلات القناة فعلية حتى تربط مصدرًا موثوقًا بها.

## حماية لوحة التحكم

- أنشئ قيمة عشوائية طويلة لـ `APP_ADMIN_TOKEN` وأضفها في إعدادات Vercel كسر، ثم أعد النشر.
- سيطلب التطبيق الرمز قبل تحميل بياناته. يحفظه المتصفح في `sessionStorage` لهذه الجلسة فقط.
- هذا قفل إداري بسيط لفريق صغير، وليس نظام مستخدمين متعددين أو صلاحيات دقيقة. لا تستخدمه كتطبيق متعدد العملاء.

## حدود التكامل الحالي

Firestore متصل بمسارات الأفكار وحالتها. R2 يتلقى نسخة من ملفات الإنتاج ويخدم الصور والصوت والفيديو عند غياب النسخة المحلية. بقية سجلات السكريبت وSEO والتحليلات ما زالت CSV؛ يلزم نقلها لمجموعات Firestore قبل اعتبار كل بيانات التطبيق دائمة. فعّل `APP_ADMIN_TOKEN` قبل إتاحة التطبيق على الإنترنت.
